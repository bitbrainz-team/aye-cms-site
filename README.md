# Aye CMS site and demos

Public landing site for Aye CMS. The Astro homepage and the Next.js and vanilla Vite demos import `@bitbrainz-team/aye-cms` from GitHub Packages. The CMS source and Worker live in the separate private `bitbrainz-team/aye-cms` repository.

## GitHub Pages

1. Push this project to the public `bitbrainz-team/aye-cms-site` repository.
2. Grant that repo **Read** access to the `aye-cms` package under **Manage Actions access** in GitHub Packages. The workflow uses its built-in GitHub token to install the package.
3. In **Settings → Pages**, select **GitHub Actions**. Run **Deploy landing page and demos**. Pushes to `main` deploy automatically after setup.

The build puts the demos under `/demos/nextjs/` and `/demos/vite/` relative to the landing page. The public Pages build uses the published package version specified in the manifests. To make future installs reproducible, commit the `package-lock.json` generated by the first authenticated `npm install`.

## Enable hosted editing

Register the pages you want to edit as Free public sites on the Aye CMS Worker. Use repo `bitbrainz-team/aye-cms-site`, branch `main`, the Pages origin (usually `https://bitbrainz-team.github.io`), and the approved numeric GitHub editor IDs for each registration. Configure one content collection per registration with the corresponding directory and omit `create` so the editor offers changes to existing pages.

| Page | Actions site ID variable | Editable collection |
| --- | --- | --- |
| Landing page | `CMS_SITE_ID` | `src/content` |
| Next.js demo | `NEXTJS_DEMO_SITE_ID` | `demos/nextjs/src/content` |
| Vite demo | `VITE_DEMO_SITE_ID` | `demos/vite/src/content` |

Set `CMS_API_URL` to the canonical Worker URL and set the site ID variables you registered. Pages without a site ID remain browsable as static pages. An enabled editor offers GitHub sign-in, AI draft preview, and Markdown or patch export.

## Local development

Authenticate to GitHub Packages with `npm login --scope=@bitbrainz-team --registry=https://npm.pkg.github.com --auth-type=legacy`, then run `npm install`. Use an account or classic personal access token with package read access.

- `npm run dev` serves the landing page on port 4325.
- `npm run dev -w demos/nextjs` serves the Next.js demo on port 3001.
- `npm run dev -w demos/vite` serves the Vite demo on port 5173.
- `npm run build:pages` builds all three into `dist/`. Set `PAGES_BASE_PATH=/aye-cms-site` to reproduce a project-site deployment.

Run the matching `npm run editor` command to use the local coding bridge, or configure a Worker URL and site ID to use hosted editing.
