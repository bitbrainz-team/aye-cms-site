# Hello World

## Aye CMS setup checklist

- [ ] Create a GitHub repository for your site.
- [ ] Install `@bitbrainz-team/aye-cms` and import the hosted editor in your browser code.
- [ ] Store your editable Markdown in the repository.
- [ ] Register your repo, site URL, and editors with the Aye CMS Worker.
- [ ] Set the Worker URL and site ID in your build, then deploy the site.
- [ ] Open Admin, sign in, and draft your first edit.
- [ ] Review the change and merge it through a GitHub pull request.
