# Vanilla Vite demo

Run `npm run dev -w demos/vite` from the site repo and open <http://127.0.0.1:5173/?admin>. Copy `.env.example` to `.env.local` in this folder to use a hosted Worker, or run `npm run editor -w demos/vite` in a second terminal to use the local bridge.

See the [site setup](../../README.md) for Pages deployment and Worker registration.
